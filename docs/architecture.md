# Architecture

## Layout

- `app/lib/main.dart`: the entry point. Sets up logging, then runs `App`.
  It holds no logic of its own.
- `app/lib/src/app.dart`: the root `MaterialApp` (light and dark themes
  seeded from indigo) and the home screen.
- `app/lib/src/logging.dart`: `formatLogRecord`, a pure formatter, and
  `setUpLogging`, which routes `package:logging` records to
  `dart:developer` (shown by `flutter run`, DevTools and `adb logcat`).
- `app/test/`: unit and widget tests, one file per source file.
- `app/android/`: the Gradle project generated by `flutter create`, with
  release signing added (see [android.md](android.md)).

## Conventions

- Code outside `main.dart` lives under `lib/src/`, grouped by feature as
  the app grows.
- Console output goes through `package:logging`, never `print`
  (`avoid_print` is enabled). Each file creates its own `Logger('name')`.
- Logic is written as pure functions where possible, with state kept in
  widgets or a few setup functions so the logic can be unit tested.
